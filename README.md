# Automation

Checks Play Store updates (force stops and retries if the page does not open) and answers incoming calls

Example add-on for the DuyGör screen reader. Install it from the DuyGör add-on store, or download the `.dgp` file from Releases.

DuyGör ekran okuyucusu için örnek eklenti. DuyGör eklenti mağazasından kurabilir ya da Releases bölümünden `.dgp` dosyasını indirebilirsin.
